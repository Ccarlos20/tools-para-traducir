# Tools Para Traducir

Herramienta web personal desarrollada para facilitar la traducción de textos en japonés.

La aplicación permite crear y mantener una base de datos de caracteres japoneses, organizándolos mediante categorías y relaciones de similitud para encontrarlos rápidamente durante el proceso de traducción.

## Funciones principales

- Analizar un texto y detectar caracteres japoneses únicos.
- Agregar y editar caracteres en una base de datos local.
- Organizar caracteres mediante categorías personalizadas.
- Relacionar caracteres visualmente similares.
- Obtener recomendaciones de caracteres relacionados.
- Buscar caracteres por categoría o por cantidad de categorías asignadas.
- Importar, exportar y combinar bases de datos en formato JSON.

Toda la información se almacena localmente en el navegador, por lo que no es necesario utilizar un servidor ni crear una cuenta.

Este proyecto fue desarrollado como una herramienta de uso personal para agilizar el trabajo de traducción y mantener organizada una colección creciente de caracteres japoneses.
